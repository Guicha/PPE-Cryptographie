
# **PyBank**

**PyBank** est un système bancaire virtuel développé en Python permettant de :

- Simuler des transactions financières en arrière-plan
    
- Tester différents algorithmes cryptographiques (RSA, ECDSA, Ed25519, etc.)
    
- Créer et gérer plusieurs utilisateurs
    
- Effectuer manuellement ou automatiquement des transactions
    
- Monitorer l’activité du système ou d’un utilisateur spécifique
    
- Collecter des métriques de performance liées à la cryptographie
    
- Tester la sécurité du système via des attaques contrôlées (MITM, replay, falsification, etc.)
